## Description of Service

Gleamit is a personal oral hygiene tracking application. It allows users to
record and manage information such as brushing sessions, reminders, brush
replacement tracking, dentist information, and dental appointments.

Gleamit can be used:

- without an account, with data stored locally on your device only
- with an optional account, which enables backend-backed cloud backup and
  restore for supported data

Cloud backup in Gleamit is intended as a personal restore feature, not as a
real-time collaborative or multi-user sync service.

On a fresh device, signing into an account may restore previously backed-up
data. If meaningful local synced data is already present on that device and the
account already has a backend backup, Gleamit may ask for confirmation before
replacing the device's local synced data with the account backup.
